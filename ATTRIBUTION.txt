MODEL AND DATA ATTRIBUTION

No external AI model ships with or is invoked by the default build. The
LocalDeterministicScribe is original repository code used to demonstrate the
redaction, schema, provenance, and human-review boundaries without a network call.

All demo patient records, interactions, identifiers, names, notes, comments, tasks,
and benchmark traffic are fictional synthetic fixtures authored for this project.

ASSETS AND TYPOGRAPHY

No external raster images, stock media, web fonts, or proprietary icon assets ship
with the application. The interface uses Lucide icons under ISC and operating-system
font fallbacks (Avenir Next, Avenir, Georgia, and generic system families); font files
are not redistributed.
